# LUO COMPUTER 10-step plan

This is the working sequence for turning LUO COMPUTER into the full LUO OS agentic runtime.

## Step 1 — Visible LUO OS tree browser
Show the embedded `luo_os/` tree inside the dashboard, grouped by top-level subsystem.

## Step 2 — Task inspector
Let the user click a task and see its plan, assigned agents, and current step.

## Step 3 — Computer playback
Show the computer action log as a step-by-step playback timeline.

## Step 4 — Session resume
Persist the active session cleanly so launch → resume is reliable across restarts.

## Step 5 — File browser
Expose the workspace files and LUO OS files through a browser view.

## Step 6 — Agent filters
Add filters for role, expertise, busy state, and task assignment.

## Step 7 — Project runner
Add controlled project execution with visible output and exit codes.

## Step 8 — Device links
Add device registration, approvals, and scope-based access.

## Step 9 — Search and indexing
Expand the LUO OS index into a real search surface over docs, code, and configs.

## Step 10 — Polish and release hardening
Clean up the UI, tighten errors, and make the system feel like a finished product.
